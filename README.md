### 効果が起きる順番

1. **ターン開始**：前のターンの防御・守護は持ち越しません。MPの自然回復はありません。
2. **各行動の直前**：生存・MP・生存している対象を再確認。通常攻撃と防御を含め、1体につき1回だけ行動します。
3. **特技の発動・着弾**：発動時にMP消費。守護/防御はここから有効。防御解除はダメージの前、浄化は回復の前に処理します。毒の重ねがけは残り3回に更新し、加算しません。
4. **各行動の終了**：行動境界を記録。守護は守った本人や術者の手番が終わっても切れず、そのターン中持続します。
5. **ターン終了**：生存している毒対象全員が最大HPの6%（切り捨て、最低1）を受け、残り回数が1減ります。毒を受けたターンが1回目。防御では軽減しません。全員の毒を処理してから防御・守護を失効させ、勝敗を判定します。片軍の最後の直接攻撃後でも毒で相打ちになる場合があります。

戦闘不能になった対象の毒・守りは消えます。浄化は発動時の毒を消しますが、その後に新しく付与された毒は防げません。スキップしても自然再生しても最終HP/MP/状態は同じです。

## v0.4の戦略ループ

1. **編成を試す**：5体・重複なし。標準戦はCOST17、軽量戦はCOST15。敵も同じ上限内です。先頭のリーダーが味方全員の最大HPを12%、または攻撃力/素早さを8%増加させます。詳細からリーダーを変更できます。図鑑能力値は補正前、戦闘中の能力値は補正後です。効果は戦闘開始時に確定し、リーダーが倒れても続きます。
2. **組み合わせを残す**：リーダー・5体の並び・ルールを3枠に保存。保存ボタンは使用中の枠を上書きします。最後の5体編成も保存します。保存先はこのブラウザだけで、アカウントは不要。保存が使えなくても対戦できます。
3. **得意な役割を探す**：名前・特技・リーダー効果で検索。役割、リーダー能力、コスト、空き枠に追加できる候補で絞り込み、HP/攻撃/素早さ/コスト順で比較できます。12体の詳細には独自の物語と、得意な役割・苦手なことを記載しました。
4. **対戦開始後に読む**：次の敵編成は開始まで非公開。「作戦」で敵の補正後HP/素早さ・特技・役割を確認できます。味方の指示は行動順の目安として表示。敵の選択は非公開で割り込み、同速はシード付き抽選です。作戦/詳細/ログを開いても30秒の入力時間は止まりません。
5. **対策を選ぶ**：ナーガ/トロルの守護は味方1体の直接ダメージをそのターン半減。優先度3で先制攻撃より早く、自分も対象にできます。防御と重ねても軽減率は増えません。イフリート/アヌビスの防御解除は、通常順で守護・防御を解除してから攻撃します。バステト/セルキーの浄化は通常順で味方1体の毒を解除しHP35を回復します。後から毒を受ける場合や、解除前に倒れる場合もあります。毒の継続ダメージは防御で軽減できません。
6. **仮説を確かめる**：結果に残りHP割合を表示。「同じ編成ですぐ再戦」、または「編成を見直して再戦」で敵・乱数シード・ルールを維持。指示の変化によって乱数を使う順番が変わるため、同じ指示を繰り返した時だけ同じ結果になります。ルール変更で再戦条件を解除。通常の「闘技場に戻る」では次の相手へ進みます。

## 対戦の基本操作

- 闘技場には敵だけを表示し、味方のHP/状態/ダメージは画面下のアイコンに集約。
- 味方を選び、たたかう・ぼうぎょ・とくぎ・おまかせの4コマンドから指示。習得済み特技は最大4つ。通常攻撃と共通防御は別枠です。
- 単体攻撃は敵、回復/浄化/守護は生存している味方を下の対象パネルから選択。全体技と共通防御は対象選択不要。戻る操作で未確定の選択を取り消せます。
- 1体の「おまかせ」はその味方の自動指示を確定。「全員おまかせ」は全員の指示を未入力に戻し、開始時の状況から自動選択します。
- 各ターンの入力は30秒。時間切れは確定済みを保持し、未入力だけ自動化。対象選択途中は未確定。背景タブから復帰しても実時間の締切を守ります。
- 行動順は守護3 → 先制2 → 防御1 → 通常0 → アンカー-2。同じ区分は素早さ順。同速はシード付き抽選。
- 演出は1倍/2倍、スキップ可能。ダメージ表示とHP更新を着弾に同期します。ログには守られた対象、毒解除、防御解除、軽減の理由を記録。
- 最大20ターン。両軍各メンバーの残りHP割合の合計で判定します。戦闘不能は0%。中断はその対戦を破棄します。

## 検証

- 決定論的な戦闘、入力不変性、イベント再生と最終HP/MP/状態の一致
- MP不足/ちょうどの残量/不正対象/手番前撃破/キャンセル、自然再生とスキップ
- 開始/行動直前/発動/行動後/終了のイベント順、毒の残り回数と守護の失効
- リーダー効果の両軍対称性・非累積性、全員の特技最大4枠
- 守護の先行/解除/重複非加算、浄化の前後関係/再対象、対策AIの合法指示
- ルールごとの敵コスト、保存破損/保存拒否、不正編成の出場禁止
- 編成保存/読込、複合フィルター、リーダー変更、正確な再戦条件
- 30秒締切、対象選択途中の時間切れ、情報パネル中の時間切れ、二重開始防止
- 敵だけのフィールド、味方HP/状態/同時着弾、ログ、中断、自然再生/スキップ
- 複数シード・編成の20ターン以内の決着

DOMテストと実ブラウザ描画確認は別です。リリース時には公開URLで狭い縦画面・横画面の操作も確認します。
