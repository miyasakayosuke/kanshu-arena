# 環獣のアリーナ v0.1

オリジナルモンスターによる5対5の戦術型ブラウザゲーム。DQMSLの戦術性を参考にしていますが、名称・画像・音源などのゲーム素材は使用していません。

## 開発
```sh
npm install
npm run dev
npm test
npm run build
```

## 遊び方
5体を合計コスト17以内で編成し、敵パーティと対戦します。各ターンの特技を選択して行動を実行します。先制・アンカー、回復、防御、毒を実装しています。

## 公開
GitHub Settings → Pages → Build and deployment → Source を GitHub Actions に設定してください。非公開リポジトリのGitHub Pages利用可否は契約プランによります。

## 既知の制限
v0.1は戦闘プロトタイプ。オンラインマッチ、反射、特性、装備、蘇生、属性耐性、専用戦闘アニメーションは後続版で実装します。
