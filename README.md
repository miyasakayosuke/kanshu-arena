# 環獣のアリーナ v0.3 Playtest

オリジナル編成ルールによる5対5の戦術型ブラウザゲーム。DQMSLの戦術性を参考にしていますが、同作の名称・画像・音源などのゲーム素材は使用していません。12体の神話モチーフのモンスターを、現在は絵文字アイコンで表現しています。

## 開発

```sh
npm ci
npm run dev
npm test
npm run build
```

Node.js 22を推奨します。React・TypeScript・Vite、テストはVitestとhappy-domです。GitHub Actionsは同じlockfileでテスト・型検査・本番ビルドを行い、成功したmainだけを既存のGitHub Pagesへ配信します。

## 遊び方

1. 5体を合計コスト17以内で編成します。アイコンから詳細を開き、編成の追加・解除ができます。名前・特技検索、HP/攻撃/素早さ/コスト順、先制・アンカー・回復・全体・毒・防御の絞り込みを利用できます。
2. 対戦中は画面下の味方アイコンを選び、特技を選択します。単体攻撃・回復はフィールドの対象アイコンをタップして確定。次の未入力の味方へ自動で移ります。
3. 「この指示でターン開始」で実行します。未入力の味方には、その時点の状況に合わせたおまかせ行動が入ります。次のターンは全員未入力に戻ります。
4. 演出は1倍・2倍を選択できます。「演出をスキップ」でも同じ戦闘結果になります。行動の予備動作、対象への着弾、ダメージ表示とHP更新を同期しています。
5. 最大20ターンで決着。20ターン目は各モンスターの残りHP割合の合計で判定します。結果から編成に戻ると次の敵編成へ進みます。中断はその対戦を破棄します。

有効な5体の編成をブラウザに保存します。保存領域が使えない場合や保存内容が壊れている場合も、初期編成でプレイできます。

## 検証

- 決定論的な戦闘、入力状態の不変性、イベントと最終HPの一致
- 対象指定・死亡後の再選択・回復・防御・毒・先制・アンカー
- 複数のシード/編成による20ターン以内の決着
- 特技の予備動作と着弾のタイムライン、全体攻撃の同時着弾
- 編成・対象選択・次の味方への移動・新ターンの入力リセット
- 連打、中断、演出スキップ、結果、ログ、再戦、破損保存データ

DOMテストはブラウザでの描画確認とは別です。リリース時には公開URLで実操作も確認します。

## 現段階の範囲

オフラインの対CPU闘技場です。オンライン対戦、ストーリー、装備、育成、蘇生、属性耐性・反射、専用のモンスター画像、音声は未実装です。今回の版は編成・指示・演出・勝敗・再戦の手触りを評価できるプレイテスト版です。
