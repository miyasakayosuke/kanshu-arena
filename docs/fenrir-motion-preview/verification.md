# Articulated motion verification

This candidate replaces the rejected mesh crouch with original-texture rigid articulation. It has not yet received independent rendered review or owner visual acceptance. Existing crouch preview results do not validate this new candidate.

The isolated contents-read CI workflow runs rights tests, rights inventory, all existing game tests, production build, specific rig checks and actual Chromium capture. It installs Ubuntu ffmpeg before encoding the preview. The workflow never deploys and is scoped only to candidate/fenrir-articulated-motion.

Required review: enlarged and approximately 130 CSS-pixel motion; neutral, lift, plant, weight transfer and recovery; light and dark backgrounds; fixed segment lengths and planted support contacts; face, cuff and chain shape stability; shoulder, wrist and hip seams; reduced motion and clean loop. Automated success is not visual approval or legal clearance.

Production game source, save data, main branch and the held awakening candidate remain unchanged. Exact CI and independent review findings will be recorded after actual capture.
