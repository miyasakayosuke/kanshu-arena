# 不死系5体の参照資料と独自設計案

調査日: 2026-10-10 UTC。調査対象は `docs/all-families-roadmap.md`、既存の全系統・悪魔・物質・粘体系の参照資料と、本作の `src/engine.ts`（ID0〜31を含む悪魔系作業版）。**本書は実装前の設計候補であり、公開仕様・採用済み数値・バランス合格記録ではない。** `AGENTS.md` と `docs/rights/release-checklist.md` を確認した。本担当の編集対象は本ファイルのみ。

## 1. 推奨する一つの案

**既存バンシーが毒を広げ、遅い中核が「残りの毒を残して待つか、消費して一体を倒すか」を選ぶ。** 生存者への有限の手当てで攻撃の機会を作る。毒の追加ダメージを無償で積み重ねる編成や、復活ループにはしない。

- バンシーID4・C3はHP/MP/ATK/SPDと3特技を変更せず、不死系へ所属させる。
- 新規はドラウグルC5、首なしの馭者C4、キョンシーC3、ヴェータラC2。純5体は **5+3+4+3+2=17**。この5体だけではC15・C16純編成はできない。
- 主な追加は、指定単体の有料攻撃が**その対象の既存の毒残回数を直接ダメージへ交換して、毒を消す**処理一つ。毒を消費する機会費用は、純系統でも混成でも残す。
- 開戦時に本人を含む不死系3体以上なら交換量が増える。開始時の所属で固定し、先頭以外でも有効。生存人数の減少で条件を取り直さない。
- 通常の回復は生存者のみ。蘇生、死亡後の行動、変身、HP1で耐える保証、追加行動、毒性の段階、DEF/WIS/属性/反射は導入しない。
- 歴史的参照から採るのは「状態を準備する役と、後から決着させる役の行動順」「有限MPと明確な対策」である。**毒を消費する交換方式は本作の創作であり、DQMSLの再現ではない。**

## 2. 原作の公式仕様と、実戦・評価を分ける

### 2020年の新生ラザマナス: 状態異常の後に攻撃を合わせる

[公式新生告知](https://cache.sqex-bridge.jp/guest/information/65150)では、毒などの状態異常に対するランダム斬撃の倍率上昇、確率で猛毒を与える息、解除可能な開幕軽減、自身の一度の翌ラウンド復活、仲間の死亡を契機にした封じ解除が別々に説明される。蘇生・回復封じを消す処理でも、執念を無効にする効果は消せない。ページ見出しは4月14日で、2020年新生の参照として後述の同年実戦記録と照合した。

公式の攻撃は**状態異常への倍率**であり、「毒の残り回数を消費する技」とは書かれていない。本作には原作の蘇生・執念・無効化装備・状態異常耐性がないため、原作の強さや対策をそのまま当てはめない。特に「不死系だから倒されても動ける」と案内しない。

[ent・2020-06-30「流行りの槍を無理矢理ヤりたい」](https://entdqmsl.hatenablog.com/entry/2020/06/30/203019)は、自分の旧構築の決定力・長期戦のMP不足・対執念装備への弱さを踏まえ、解除、毒、主力攻撃の順番を組み直した記録。主力を動かす準備を重視する一方、実戦では読み切れず無難な選択に寄る難しさも認める。これは一人の使用感で、母数付き勝率やコミュニティの総意ではない。個別URLの直接取得はcache missだったため、[本人の過去記事一覧に掲載された同日本文](https://entdqmsl.hatenablog.com/?page=2)を読んだ。特定週のウェイト・全試合数は確認していない。

**本作への判断:** 毒役より中核を遅くし、守護と回復でその一手を用意する。ただし全員に行動保証を配らず、速攻の集中や途中の清めで計画が崩れる余地を残す。

### 2022年のスカルスパイダー: 毒の継続強化は別の設計

[公式追加告知](https://cache.sqex-bridge.jp/jp/ja/guest/information/87285)の検索索引本文では、開幕の毒と毒性深化、同系統の通常攻撃変更、毒ではない相手への大きな倍率を確認した。本文ページの直接再取得には失敗したため、索引で確認できた範囲を超える詳細・数値を公式確認済みとはしない。

[黒豆・2022-10-22の考察](https://mamepan.net/entry/skull-spider)は、毒を解除する側にも判断を迫る設計、蘇生を前提にしない場合のHPの重要性、他編成への出張可能性を論じる。これは登場直後の評価であり、その時点で十分な実戦勝率を測った報告ではない。同記事の☆0表はHP760／MP227／ATK312／DEF529／SPD402／賢さ230、☆4表は別欄。公式能力画像と実機値は今回照合していないので**二次資料の掲載値**とする。MP65の技なら☆0掲載MPの28.6%、MP108なら47.6%という支出規模になるが、☆・技強化・装備・追加行動を混ぜた実戦再現計算ではない。

**本作への判断:** 原作の「早く倒される利点」は死亡後機構込みで成立する。死亡後に何もしない本作へ、低HPだけを輸入してはいけない。また、毒を消さず追加の大火力を載せる案は既存の強い毒混成も強める。そこで、継続強化の代わりに、残りの毒を明示的に失う単体交換技を選んだ。原作の倍率・割合・毒の段階数は使わない。

### 2023年のGP評価: 強い仕掛けと、実際に通せるかは別

[黒豆・2023-08-05の系統パーティ評価](https://mamepan.net/entry/keitou-ranking)は、前年から増えた毒・解除・執念関連の選択肢を評価しつつ、通常ルールでは反転した行動順や対執念装備等により仕掛けが通らない対面も記す。順位は著者の定性的評価で、公式ランキングや全試合勝率ではない。2020年の構築と同一環境の証言に合成しない。

**本作への判断:** 条件付きの大きな数字だけで合格にしない。毒付与役の早期撃破、清め、守り、MP切れに対して、実際に決着の手番が作れるかを測る。原作にあった蘇生封じや反射を本作の対策一覧へ書かない。

## 3. 調査時点のエンジンで守る契約

- 5対5、HP/MP/ATK/SPD、特技は最大4。通常攻撃と防御は特技枠を使わない。
- 通常単体攻撃の基礎は `power + ATK × 0.38`。乱数0.90〜1.10、守り・自然障壁の直接ダメージ軽減を受ける。通常攻撃の基礎はATK。
- 既存の全体`hit`は0.5倍されるが、`poison`はその全体攻撃補正を受けない。バンシーの毒霧は「全体の小攻撃＋毒」である。
- 毒は3回までの残ターン終了回数。付け直しは残3へ更新するだけで重ならない。各回は最大HPの6%を端数切り捨て、全行動後に両軍へ処理する。守り・自然障壁は経過毒を軽減しない。
- `cleanse`は生存する味方単体の毒を消して固定量回復する。毒を消すより前にキャラクターが行動したかどうかを混同しない。**SPDが高い清めは、同ターンのバンシーの新しい毒より先に動く場合がある。** その場合は前ターンの毒を消せても、後から付く毒を予防しない。
- `protect`は指定味方への直接ダメージ半減。攻撃を使用者へ転送せず、毒経過は防がない。
- 命中前解除は守り・自然障壁・竜気・修復待機が対象。現在は獣の群気を外さない。命中後解除とは範囲が違う。
- 行動順は優先度→SPD→同速時シード。1回の指示から複数の行動を追加しない。指示時点でMP不足なら不適法。適法な有料指示が敵MP減少で行動時に不足した場合、現行悪魔版は元のキュー位置で通常攻撃へ切り替える。
- 守りの解除は毒を消さない。毒消費型技も守りを解除しない。二つの役割を一本の必須技へまとめない。

## 6. 毒交換の厳密な処理案

これは本作独自の追加仕様。既存の毒を使い、新しい状態ゲージや死亡状態を増やさない。実装上は小さなSkill側の指定と、既存の毒0イベントを使うことを想定する。実際のフィールド名は実装担当が既存型に合わせて決める。

1. **行動実行時・実際に命中する生存対象**の毒残回数を読む。指示時の値を予約しない。0〜3の整数に限定する。対象変更が起きた場合、元の指定先の毒を横取りしない。
2. 交換係数は通常14、本人を含む開戦時の不死系3体以上で22。所属条件は先頭・現在HP・現在の生存人数から独立。家族条件そのものを解除可能なバフとは表示しない。
3. 攻撃基礎は `48 + attackFor(actor) × 0.38 + 係数 × 消費した毒回数`。係数部分も通常の直接ダメージと同じ乱数・守り・自然障壁の軽減を受ける。固定割合HPダメージや軽減無視にはしない。
4. 有効な命中を処理する際、捕捉した残回数を0へし、消費回数と毒0を明示したイベントを一度だけ残す。ダメージで撃破する場合も、撃破時の自動毒消去に隠さず「何回を交換したか」をログ・再生で識別できるようにする。
5. **通常14でも条件付き22でも毒は全消費**。部分消費、家族条件だけ消費免除、消費後の自動再付与はない。毒0でもMP18の普通の低威力攻撃として実行可能だが、追加分0。
6. 後で別の毒技が命中すれば新しく残3になる。それは新しい有料行動の効果であり、消費した毒が自然に戻ることではない。消費し終えた対象には、そのターン末の毒経過ダメージが発生しない。
7. 不適法な指示、MP不足による不発、実行前の戦闘不能では毒を消さず、追加ダメージも与えない。敵MP減少で通常攻撃へ切り替わった場合も、交換効果は引き継がない。
8. 指定単体・1ヒット専用とする。全体、ランダム連撃、命中前解除、MP削りとの同時搭載はこの波では認めない。毒交換から追加手番・竜気・HP回復を発生させない。
9. 能力無効比較では係数追加と消費の双方を外す。「家族ボーナスなし」の比較では14固定のまま消費する。両者を混同すると、機会費用をなくした版を誤って基準にする。

### リーダーなし・ATK42の比較

| 毒残回数 | 通常14の基礎 | 不死3体条件22の基礎 | 普通のMP10打撃 |
| ---: | ---: | ---: | ---: |
| 0 | 63.96 | 63.96 | 77.96 |
| 1 | 77.96 | 85.96 | 77.96 |
| 2 | 91.96 | 107.96 | 77.96 |
| 3 | 105.96 | 129.96 | 77.96 |

表は乱数・軽減・端数処理の前。HP200の相手に毒3を残す場合、全て通れば12×3=36の経過ダメージがある。条件付き交換は基礎66を上乗せするが、その36を捨ててMP18と一手を使う。守りがあれば追加分も半減され、合計の将来ダメージを減らす場合がある。それでも**敵が動く前に倒す**価値があるか、相手の清めで毒が消える前に交換するかが判断になる。

毒3を全て残した値と、交換による直接ダメージを足して「総火力」と表示してはいけない。残回数1では差が小さく、普通の打撃＋その回の毒を残す方が有効な場面を意図している。上限3回のため、大HP相手へ無制限に増えるダメージにはならない。

## 7. 相手の選択と、既存の強い毒混成を守る検証

### 実在する対処

- バンシーを先に倒して、新しい毒を止める。中核に毒技を追加せず、二役の依存を残す。
- 中核をその手番前に集中撃破する。行動保証も死後攻撃もない。
- 付与後・中核前に清められる順番なら、そのターンの交換量を下げる。前から付いている毒を先に消すこともできる。ただし毒を予防する免疫は付かない。
- 守り・守護で交換ダメージを半減する。交換後はその毒の経過がないため、防御が時間を稼ぐ意味がある。馭者に剥がされる可能性も読み合いに残る。
- 悪魔のMP減少でMP18の支払いを崩す、支援を攻撃して有料の手当てを強制する、毒のない相手へ対象を変えさせる。

## 8. 後の超常系: 混成用中核だけを小さく追加する

[2023-01-31の公式ルビス告知](https://cache.sqex-bridge.jp/guest/information/88920)では、本人を含むメイン系統の種類数が技・支援・リーダーに関わり、サブ系統は数えない。[黒豆・2023-02-03の9周年杯第1週実戦](https://mamepan.net/entry/9syunenhai-1)はW140・特殊系統制限・一部禁止の条件で異なる系統を組み合わせる過程を記す。中核の効果と、集めた各メンバー自身の強さを分ける姿勢が参考になる。これを万能中核の証明にはしない。

**後続の短い提案:** 完全創作の星図を綴る存在「綴り星」（仮名、C5）を超常系の1体目にし、広い毒・全体直接攻撃に対して一度の応答を選ぶ。開戦時に本人を含む分類4種類以上なら、**共通の残1回を消費する有料行動**を使える。

- 案A: 通常順、MP24程度を払い、生存する味方全員の現在の毒を消す。回復0、毒予防なし。後から毒を付け直される。バンシー75→綴り星57→ドラウグル49の間なら交換前に毒を消せるが、ナーガ39の後からの毒は防がない。
- 案B: 最速の守護順、同額を払い、生存する味方全員へそのターンの既存の守りを配る。直接ダメージ半減、経過毒は軽減しない、障壁と重ねず強い方のみ、通常の解除が通る。
- **AとBは合計一度。** 二つを一手で同時に使わず、片方を使えばもう片方も残0回。MP支払いと一手を要する。自動発動、毎ターン清め、MP回復、蘇生、継続回復、免疫はない。残りの特技枠は低い単体打撃と単体守護程度とし、最大4を守る。

種類数は開始時固定、未所属は数えず、同じ分類は一つ。4から5へ増やしても追加上昇しない。**中核＋自然3体では5枠に4分類を入れられず、広域応答は使えない。** 3体統一中核との併用を避ける条件にする。現在のエンジンでは普通の`heal/cleanse/protect`の`all`だけで味方全体に作用するわけではないので、実装するなら対象解決と共通の一度きり判定が必要。この波に含めず、後で一つの小さな機能として検証する。

例は綴り星C5／フェンリルC4／バステトC3／ナーガC2／ヴェータラC2＝**C16、超常・獣・自然・不死の4分類**。獣2体、自然1体、不死1体なので、複数の3体中核条件を同時起動しない。初期値はHP185/MP58/ATK25/SPD57程度を仮置きし、守りを消せる速攻、毒の再付与、単体集中にも負けられるかを調べる。既存バステト等との中核置換、4種類未満、応答なしを比較し、広域応答を持つC5が全ての強い混成で必須にならないかを確認する。これは短いロードマップ案であり、不死波の採用値・実装要件ではない。超常中核だけを自然優勢の唯一の解決策にせず、全系統が揃った後で、毒の広さ・再付与・清めの手番・回復量を横断したシステム全体の検証を別に行う。
