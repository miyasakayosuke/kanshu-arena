# v0.20.16 行動済みの味方を区別する

2026-10-12。基準は公開v0.20.15 commit `4fad2dc598168f1161bf3bbd5dc221fdbe8354e8` / tree `7aebc1a25d14b3da45ec2c79078d69ee4132ccd8`。公開前の検査記録。

味方の顔アイコンをその場に固定したまま、コマンドを終えた生存者を静かな薄表示と「行動済」で区別する。未実行は「待機」、実行中は「行動中」、倒れた味方は「戦闘不能」のまま。文字による状態を読み上げ用の説明にも含める。HP・MPや状態異常の文字には薄表示を適用しない。

既存タイムラインの実際のcastから開始・終了区間を記録する。連続攻撃は最後の回復区間まで一つの行動として扱い、自動修復・毒・補足通知や行動前に倒れた個体に実行済みを付けない。既存のcue・効果時刻・合計時間は変えない。スキップ・自然終了・次ターン・再戦・中断のタイマー破棄と一緒に表示を戻す。

実行時の変更はApp.tsx、playback.ts、style.css。engine、能力値、AI、乱数、保存形式と3チーム、37体の絵・紹介・106件の特技文・8つの物語、依存・告知全文は保持。新しい画像・映像・音声・文章素材や外部コードを取り込まない。

最終検査は[release-validation-v02016.json](../../release-validation-v02016.json)へ記録する。候補は2,827テスト/141ファイル、15権利セルフテスト、TypeScript/build、独立86検査を通過。リリース版も2,827テスト/141ファイル、15権利セルフテスト、TypeScript/build、source/dist告知を通過。736対戦のレポートはsource.gitCommit・source.gameVersionのみを除き基準版と完全一致。実ブラウザでは公開後に顔の薄表示と文字の見え方、実行中/実行済/待機/戦闘不能、スキップ・次ターン・中断・再戦を確認する。動きを抑える設定でも静的な状態表示を保つ設計だが、実ブラウザの設定検証を行わない場合は未検証と記録する。

実端末のタッチ、スクリーンリーダー音声、性能、専門家の法律確認は含まない。既存の大きいJS chunkの注意を残す。権利検査は許諾・非侵害の法的判定ではない。
