# v0.20.19 戦闘ログのキーボード操作

2026-10-12 UTC / 2026-10-13 JST。基準は公開v0.20.18 commit `5f2f7e8f159005477755237f936589406c51b78a` / tree `a63e4cc060b16d75ac3504855ba4c4b7d1ceeacd`。公開前の実装と検査範囲。

## 修正

戦闘ログには従来、開いた時のフォーカス移動とTabの閉じ込めがなく、見た目のダイアログの背後に操作先が残っていた。既存の全文・指示・イベント記録を専用ダイアログへ移し、閉じるボタンへの初期フォーカス、Tab/Shift+Tabの循環、閉じたdetails内の除外、Escape・閉じる・背景クリックでの終了を実装した。長いログではフォーカス項目が見える位置へ移る。

背景をinertにし、元のスクロール状態を閉じる時に戻す。元のボタンが残っていればフォーカスを戻し、なくなれば現在画面の論理的な操作先を使う。ブラウザ履歴などで対戦中断確認が開く間はログを休止し、確認をキャンセルすればログへ戻る。試合終了時の受付への自動移動を保持する。
