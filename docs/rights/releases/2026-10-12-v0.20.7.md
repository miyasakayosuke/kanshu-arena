# v0.20.7 妖狐の新しい姿と関節アニメーション

2026-10-12、最終公開前記録。基準 v0.20.6 commit `bb78f6c319df500139e5938bca41d6d210e19393` / tree `b65e5ba0273e19534ce388f650742f6962e78647`。レビュー済み候補 tree `ceed960083086f8e1ba87c2b8ac5c5d1ae56c67a`。

## 変更

ID 0 の妖狐だけを、新規コードで描いた表情の読みやすい姿へ更新。図鑑・顔・静止代替表示と戦場の 17 個の SVG パーツは共通の幾何形状を参照。頭・耳・尾・前足・まぶた・口を独立に動かす。戦場の同じマウントではパーツを共有し、完全に準備ができるまでは静止代替表示を保つ。パーツが揃えば静止画像の遅延・失敗と独立してリグを描く。

本編の 800 ms 着弾、90 ms 保持、460 ms 復帰へ姿勢を写像し、実 impact 観測まで戻りを始めない。倒れた姿勢の保持と再戦時の解除、動き抑制、倍率、スキップと後始末を検証対象に含める。能力値、HP/MP、乱数、AI、イベント生成、保存形式と他 36 体の登録・動作は変更しない。前版のホーム整理・全 37 体の紹介を保持。

## 画像処理と計測の区別

コード上で 17 パーツ、通常 1 体につき 16 回の画像描画、5 体なら 80 回を使う。名目パーツ RGBA 容量は 2,399,552 bytes。静止代替画像や SVG/ブラウザの中間領域は別。最大 20 パーツ、名目 8 MiB のガードを設ける。フレームごとの SVG 生成、Image 生成、外部素材要求は行わない。これらはコードと制御されたテストの結果で、実機メモリや fps の測定ではない。

最終集計は [release-validation-v0207.json](../../release-validation-v0207.json)。独立レビューで死亡後の呼吸、首毛の切り抜き、静止画像に依存したリグ準備ガードの 3 件を修正済み。レビューはソース・テストと Sharp/librsvg + Canvas による実レンダラーの制御された描画であり、実ブラウザ・WebKit・実機結果ではない。

公開後には実サイトで版番号・アセット、妖狐の新しい全身と顔、初回読込み、待機・攻撃・直接被弾・死亡・再戦・倍率・スキップ、縦長と短い横画面、保存枠と console を別途確認する。UI にない重複 5 体や画像失敗注入・実 impact の人工遅延は自動検証のまま区別する。動き抑制設定を実ブラウザのサポートされた操作で到達できない場合、その限界を記録する。前版の [実ブラウザ確認](../../v0206-live-verification.md) は新しい描画の確認を代替しない。
