# 権利確認の残件と専門家への質問

2026-10-10時点。日本での個人開発・公開を中心にした調査メモ。法的判断、許諾取得、商標/特許クリアランスを完了した記録ではない。正式公開地域や収益化方法は未確定。

## 確認した事実

- v0.11候補の配信対象は、コードで作成したSVG3体、端末が描画する絵文字、Canvas/CSS、React系コード等。監査した追跡ファイルと配信物にDQMSLの画像/音声/抽出プログラムは見つからなかった。これは包括的な非侵害調査ではない。
- 既存README・研究資料はDQMSLの参照対象と出典URL、数値・短い名称を記載している。リンク先の画像/アーカイブそのものは配信対象に含めていない。参照記録は隠さず、引用範囲と目的も次回点検する。
- これまでの配信JSにはReactの短いライセンス参照コメントがあったが、参照先LICENSEと許諾全文が配信物に含まれていなかった。今回、第三者告知全文と到達導線を追加する。公開URL確認は各リリース記録に残す。

## 調査の一次資料

下記は一般論・利用条件の出典であり、本作の許諾書ではない。更新時に現在の本文と適用範囲を再確認する。

- [文化庁・著作権等に関するQ&A](https://www.bunka.go.jp/seisaku/bunka_gyosei/kibankyoka/faq/index.html): アイデアと具体的表現、制作委託等の基本を確認する。
- [文化庁・AIと著作権](https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html): 「AIと著作権に関する考え方」とチェックリスト。AI支援を理由に一律に安全としない。
- [DQMSL公式・動画/生配信/画像投稿ガイドライン](https://www.dragonquest.jp/dqmsl/videoguideline/): プレイ動画・画像の投稿条件。別ゲームへの画像・音声等の組込みを許す根拠にはしない。
- [特許庁・商標制度の概要](https://www.jpo.go.jp/system/trademark/gaiyo/seidogaiyo/shotoha.html): 名称等の商標の検討用。リンクしただけで本作の検索を実施したことにはならない。
- [特許庁・商標活用ガイド](https://www.jpo.go.jp/resources/report/sonota/document/zaisanken-seidomondai/2018_01_guide_youyaku.pdf): 先行商標調査の進め方の参照先。
- [Open Source Initiative・MIT License](https://opensource.org/license/mit): 一般的な許諾条件。実際の同梱文はインストール済み各パッケージのLICENSE原文を使用する。

## 相談時の資料と承認

対象commit、素材台帳、依存告知、参照した内容、独自変更、比較画面/短い動画、公開状況・予定地域、上表の優先質問をまとめる。未確認事項を「確認済み」に置き換えない。専門家との連絡、資料送付、費用、契約は所有者の別途承認後に行う。一般調査だけで最終公開の適法性は保証しない。
