# 全系統のプレイ可能な到達点

開始点: v0.11 / `ff52abef77a2a719fd39e0b21a7a83ba7e534f28`。更新日: 2026-10-10 UTC。

この計画の「全系統」は、**通常7系統の純5体編成と、超常系の混成向け中核**を指す。DQMSL後期の超魔王・超伝説に相当する変身・二者交代を完了条件には加えない。詳細な歴史的区分・版・出典は [参照資料](all-families-reference.md) に分けて記録する。

## 完了条件

- 通常7系統は、それぞれ異なる5体でCOST17以下の推薦編成を持つ。主力と支援の役割、核を選ぶ意味がある。
- 超常系は1体以上の混成用中核と、COST17以下の推薦混成を持つ。純5体は必要ない。
- ゲーム内で所属、支援対象、発動条件、資源・期間、実際に使える対策が読める。
- 新規キャラクターには独立したシルエットの本作用アート、主力には判別できる動き・効果がある。
- 同一AI・固定シード・左右交換・ミラーと能力を外した比較を記録する。既存の強い合法編成を検証から除外しない。
- 旧保存、最大4特技、MP、30秒入力、敵だけのフィールド、静止した味方アイコン、同条件再戦を維持する。
- 権利台帳、告知、テスト・型検査・ビルド・CI、実際の公開ページの画面と操作を確認して各波を公開する。
- 自動対戦の成績を人間の公平性・楽しさの証明とは扱わない。権利ゲートも法的な非侵害判定ではない。

## 段階的な公開

1. 竜系: 蓄積と解放、3体条件、固定基礎ダメージを追加し、従来の試合結果の不変性を検証。
2. 物質系: 自然の障壁と異なる後攻反攻を一つの主要判断に絞る。
3. 粘体系・悪魔系: 資源を守る側と、資源を投じる側の相互作用を検証。実装規模に応じて別公開。
4. 不死系・超常系: 有限の復帰と混成支援の境界を検証。実装規模に応じて別公開。
5. 全8分類の推薦編成、フィルター、旧保存、横断対戦、公開アート/効果、権利台帳を再点検して到達を報告。

各波のバランス記録には、採用値、未採用候補、既知の苦手対面、AIの限界を残す。
