# 全系統のプレイ可能な到達点

## 2026-10-11 公開到達点

37体・通常7系統のCOST17以下の純5体編成と超常系の混成中核は、[v0.18.2](https://github.com/miyasakayosuke/kanshu-arena/commit/f655b9ff4ee661abe5f96501a9dd44ec3f09f746)で公開済み。旧保存、編成、対戦・再戦、HTMLライセンスを実ブラウザーで確認しました。以下の版別の「公開待ち」「停止中」は当時の履歴で、現在の公開状態ではありません。

続く[v0.18.5のCI/Pages](https://github.com/miyasakayosuke/kanshu-arena/actions/runs/38110631459)と[実画面確認](live-qa-v0185.json)では、短い縦画面の戦場・スクロール・対象選択・再戦、通常の縦横画面、全文ライセンスを確認。v0.18.4で発生した短画面の行縮みも、失敗の記録を残して修正しました。能力・AI・保存形式はこの表示修正で変えていません。

ロスターを遊べる到達点と、相性・楽しさ・権利面の最終品質は別です。元の混成対策・リーダー案の不合格は維持し、後続の純物質/純悪魔の結果と混同しません。人間による公平性・楽しさの確認と専門家の権利レビューは未完了。次は既存の記録から、対策技が間に合わなかった場面をプレイヤーが読めるようにします。

## 完了条件

- 通常7系統は、それぞれ異なる5体でCOST17以下の推薦編成を持つ。主力と支援の役割、核を選ぶ意味がある。
- 超常系は1体以上の混成用中核と、COST17以下の推薦混成を持つ。純5体は必要ない。
- ゲーム内で所属、支援対象、発動条件、資源・期間、実際に使える対策が読める。
- 新規キャラクターには独立したシルエットの本作用アート、主力には判別できる動き・効果がある。
- 同一AI・固定シード・左右交換・ミラーと能力を外した比較を記録する。既存の強い合法編成を検証から除外しない。
- 旧保存、最大4特技、MP、30秒入力、敵だけのフィールド、静止した味方アイコン、同条件再戦を維持する。
- 権利台帳、告知、テスト・型検査・ビルド・CI、実際の公開ページの画面と操作を確認して各波を公開する。
- 自動対戦の成績を人間の公平性・楽しさの証明とは扱わない。権利ゲートも法的な非侵害判定ではない。

## 段階的な公開

1. 竜系: 蓄積と解放、3体条件、固定基礎ダメージを追加し、従来の試合結果の不変性を検証。
2. 物質系: 自然の障壁と異なる後攻反攻を一つの主要判断に絞る。
3. 粘体系・悪魔系: 資源を守る側と、資源を投じる側の相互作用を検証。実装規模に応じて別公開。
4. 不死系・超常系: 毒交換・有限の手当てと混成支援の境界を検証。実装規模に応じて別公開。
5. 全8分類の推薦編成、フィルター、旧保存、横断対戦、公開アート/効果、権利台帳を再点検して到達を報告。

各波のバランス記録には、採用値、未採用候補、既知の苦手対面、AIの限界を残す。

## 全系統到達時の品質ゲート（v0.14診断で追加）

v0.14粘体系はプレイテストとして追加する。既存の自然系毒・回復シェルは旧ユニット入りでも高勝率で、新しい全体攻撃役との合法混成には97–99%の診断例が残る。この状態を最終品質として完了扱いしない。

通常7系統＋超常混成の実装後、同一COST上限・同一AI・固定シード・両向き・ミラーの系統横断行列を作り、既知の強い自然/混成を必ず含める。毒・回復・守護の一般的な支配性を対象に、意図を説明したシステム調整を独立の一段階として行う。過去の完全回帰を黙って更新せず、変更するルールと旧ユニットへの影響、反証例を記録する。目標勝率への数値合わせではなく、役割別の対策と人間プレイの確認を完了条件に含める。

## v0.17 ローカル到達点と公開の区別

37体・25体の本作用SVGを収録し、通常7系統の純5体COST17以下と超常の4分類混成C17を推薦できる状態にした。ヤヌスは開戦時の所属種類数を固定し、二つの広域支援で共通1回を持つ。生存味方の現在毒除去（HP回復0）と今ターン守りから一方を選び、5分類の追加ボーナス・蘇生・MP回復はない。C15の毒混成とC16の障壁混成も合法な反証候補として保持する。

ここはロスター/UI統合の状態であり、品質・公開の完了宣言ではない。最終Lab統合、同額横断行列、一般的な毒/回復/守護のシステム調整と人間プレイ確認を残す。v0.13以降の新しい公開はまだ行っていない。既存のGitHubツリーアップロードが二度取り消され、公開は停止中。取消を別経路で迂回しない。最終commit、CI、公開画面・クレジットの実取得確認は公開を再開できた段階で別に記録する。

## v0.18のローカル候補

全7純編成と超常混成の実装後、227,712予定対戦と300件の完全再現を確認した。元の混成対策・リーダー変更の失敗を残し、新128シードでの既存純物質/純悪魔の確認を根拠に、毒初撃0＋重複予定を考慮する自動指示を別リリース候補へ移す。ヤヌスは別の共通対面で確認した5分類の例を推薦し、追加ボーナスは付けない。[採用判断と限界](playtest-adoption-v018.md)。

全ステータス・コスト・技・所属とフェンリルの能力は維持。純自然はC15で、強いC17純編成への苦手対面が残る。相性や自動指示の偏りを含むプレイテスト改善であって、全体の均衡を完成したとは扱わない。公開停止のため、CI/Pagesと実際のクラウドブラウザーでの新4波・旧保存・縦横画面・権利表示の確認は未完了。全系統の最終完了条件は閉じていない。
