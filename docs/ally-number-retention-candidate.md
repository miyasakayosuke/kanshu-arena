# v0.20.17 味方の連続着弾を読み取る表示

## 範囲

v0.20.16 公開コミット `dc65454c31d23e969f98390af1942e938b097204`、ツリー `8faf92d4b349e281bdf1eb3ca88b8ee1e2efd966` を基にした表示だけの変更です。

連続攻撃の次の着弾で、直前の味方のダメージ数字が消えていた問題を修正します。各数字を通常速度では680ms、2倍速では340ms保持します。次の着弾・別の対象への着弾・次の行動があっても、個別の期限まで表示を残します。

- 一人あたり最新4件まで。上限に達したら最も古い数字だけを入れ替え、数字を重ねません。
- 同時のHPダメージとMP減少は、別々のラベルと色で表示します。
- 顔の領域に4行分を確保し、HP・MP・行動状態の行を覆いません。
- 状態と応答のバッジは、HP・MP・行動状態の下に独立した領域を設けます。折り返した文字の高さに合わせて下へ伸びるため、数字を覆わず、顔とHP・MPの位置も動かしません。
- 動きを抑える設定では動かさず、同じ期限まで静止表示します。
- 戦闘不能になった味方の最後のダメージも表示します。
- スキップ・再戦・次のターン・中断移動では表示とタイマーを破棄します。

戦闘のHP/MP更新は従来の着弾時刻のままです。表示キューから戦闘イベントを再適用しません。能力・AI・乱数・保存・エンジン・再生タイムライン・行動済み表示を変更していません。

## 参考の扱い

提供された動画の「行動の予兆 → 着弾 → 数字を読む短い間」を表示設計の参考にしました。動画・画像・音声・既存ゲームの素材は配布物へ追加していません。

## 確認

専用9テストで通常/2倍速、同一/交互の対象、HP/MP同時表示、各数字の期限、安定したキー/行、4件上限、戦闘不能、HP再適用なし、スキップ・新ターン・中断・再戦後の残像なしを確認します。統合版の全体テスト・権利検査・ビルド結果はrelease-validation-v02017.jsonに記録します。実際の数字とHP/MPの配置、短い画面、ライフサイクルは公開後に実ブラウザで検査します。

ぼうぎょ・毒・自然系の守りが併存する状態と4件の数字、状態/応答バッジの別領域はDOM/CSSの構造として検査します。これは実ブラウザの画素配置の合格とは別です。

既存の物質系回復テストは、数字の直親から味方を特定する前提を、新しいラッパーに合わせて最寄りのcommanderを読む形へ変更しました。回復先・HP・非復活の期待値は変えていません。
