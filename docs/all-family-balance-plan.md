# 全系統到達時のシステム調整: 検証前の仮説

2026-10-10 UTC。これは未実行の検証計画で、採用済みの仕様や改善結果ではない。通常7系統と超常混成の実装後に別の調整波として行う。従来の完全回帰結果、未採用候補、強い合法編成は保存する。

## 問題の位置

v0.14・v0.15の固定AIコホートで、玄武を含む自然の毒/回復混成に約95–99%という支配的な例がある。旧ユニットへの置換でも高く、直近の新規中核だけを弱めて解決したとは扱えない。純チームのC15対C17、選んだ相手の集合、同じCPU方策という制限は結果と一緒に示す。

現在の通常全体hitは `(威力 + ATK×0.38)×0.5`。一方、全体poisonは同じ全体補正を受けず、初撃に `威力12 + ATK×0.38` を与え、さらに対象最大HPの6%を残3回付ける。再使用でも初撃は全員に与えられ、毒の期間が3へ戻る。したがって、毒を付ける広さと、即時全体ダメージを同じ手番で得られる効率を最初の仮説にする。玄武の障壁、回復、各人の速度を一度に変えて原因を不明にしない。

## 先に固定する比較

1. 現行ルールを保存した対照。
2. 毒の初撃に通常全体攻撃と同じ0.5補正を適用する候補。毒のMP16、6%×3回、解除可能性と再付与は不変。
3. 毒の初撃を0にし、状態付与そのものに一手を使う候補。0を最低ダメージ1へ丸めない。毒のMP16、6%×3回は不変。

この順序・候補は結果を見る前の機構上の比較で、50%へ寄せるための無制限な数値探索ではない。現行と候補は同じ実装エンジンの隔離設定で比較し、片側だけ変更しない。毒を使わない編成の旧結果が変われば、その原因を調べる。

毒の初撃を変えると、現在のCPUの毒評価（毒0の相手に2回分だけ加点）や同じターンの複数毒予約が問題になる可能性がある。必要なら「既存AIのままの機構比較」と「同じ公開情報だけで更新した毒評価」の比較を別々に残す。敵の注文を読むこと、未来のMPを借りること、評価用だけ有利な方策を使うことはしない。人間が選べる合法な毒の重ね掛けは消さない。

## 横断行列と反証例

- 同じCOST17上限の全7純チームと超常推薦混成を、同じシード・両向き・ミラーで対戦する。純自然C15をC17と偽らず、別に同額C17の自然中核混成も含める。
- 全系統で中核条件を満たす厳密C17の候補を結果を見る前に固定する。総コストが同じでも速度・役割・相性は同じではないので、単一の平均を系統順位と扱わない。
- 既知の自然+ねりこぶし2型、旧毒3体、物質の強い混成、フェンリル速攻、MP削り、ドラウグル+遅いナーガの再付与、ヤヌス+毒混成を外さない。
- 毒役の数、単体解除役の数、有限全体解除、回復/守護、解除/先制の各役割を含めた追加コホートを分けて報告する。
- 中核を外す同額置換、自然障壁だけ無効、毒だけを変える比較を分離する。新キャラが必要に見えるよう不利な旧編成だけを選ばない。

## 判定に使う実測

勝敗に加え、毒の初撃/経過ダメージ、毒付与と期間更新、解除時に失われた残り回数、回復量/余剰、守りと実際に防いだ攻撃、MP支出、行動前撃破、試合ターン数、判定決着、残HPを読む。ドラウグルの追加ダメージと捨てた将来毒、ヤヌスが清め/守護/温存を選ぶ頻度も確認する。単なる特技の所持を対策の実行と数えない。

候補が新しい一強、極端な長期化、毒役の実質無用化、操作説明と実際の不一致を作れば不採用とし、その結果も保存する。採用時は旧ユニットへの意図した影響、変更した説明・テスト、旧セーブ互換、通常/倍速/スキップの値一致、実際の公開画面と手動操作を確認する。自動対戦だけで人間の公平性・面白さの証明とはしない。

[事前固定データ](all-family-matrix-freeze.json) に24編成（うち厳密C17は20）、先頭と全枠の順序、主行列16シード、対策確認用64シードと未決着時の追加64シードを固定した。既知の強い編成は過去の結果を受けて含めており、母集団の無作為抽出ではない。毒の初撃スケールを変えた対戦結果は、この固定時点ではまだ見ていない。全てのシード集合は互いに重複しない。

既知の2型は `[14,3,6,10,28]` と `[14,6,9,10,28]`。以前の `[14,3,9,10,28]` は現行C18なので本試験へ入れず、過去資料には残す。推薦8組と、毒3体、遅いナーガの再付与、ヤヌスの毒/障壁混成、各中核の役割の違うC17混成を含める。COST17上限の全行列と、相手も厳密C17である部分を別々に表示し、C15の純自然を同額と呼ばない。

以下はリリースを保留するための事前のスクリーニング判断で、50%へ合わせる目標や人間の公平性の証明ではない。

- 既知の2型は、両集計区分で勝点率90%未満となり、厳密C17相手の対応比較で相手側勝点率が10ポイント以上改善すること。
- 2型それぞれに、下記3つの固定対策候補のうち異なる役割の2つ以上で、対策側勝点率60%以上・シード単位の近似95%区間下端が50%超・両配置でも対策側の勝点率が50%超となること。50%は対策側に有利な対面が実際に示されたかの境界。区間はこのCPUとシード変動についての目安で、人間への一般化や多重比較済みの法則ではない。
- どちらかの集計で新たな90%以上の行が現れたら、その原因を調べるまで採用しない。ミラーや弱い相手の追加で薄めない。
- 20ターン判定の割合がどちらかの集計で5ポイント超増えた候補は採用しない。個別対面で25%以上が判定なら内容を点検する。

追加は、固定3対策のうち2つ以上で「勝点率60%以上かつ両配置で50%超」をすでに満たすが、近似95%区間下端が50%を超える対策が2つ未満のときに限る。その方策・初撃スケール・自然型の組で3対策すべてに追加64シードを適用し、最初の64と合わせた128で一度だけ判定する。最初の64の結果も残す。点推定または配置条件を満たす候補が2つ未満なら明確な不合格なので追加しない。他の判定ゲートの不合格は追加シードで帳消しにしない。編成、シードの値、閾値は変えない。

## 実装・計測時の落とし穴

毒の威力だけを0にしてもATK加算が残る。また通常のダメージ関数は0を1に丸める。状態のみの候補では初撃を明示的に省略し、対象ごとの乱数消費は保持する。試合中の撃破や再選択によって後の乱数列が変わることと、同じターンの未変更処理で余計に乱数をずらすことを区別する。

守りと自然障壁は強い方だけが作用し、毒の経過ダメージを防がない。初撃が減ると、それまで倒れていた相手が回復/解除/修復を実行し、同時に生き残って毒を受ける回数も増えるため、毒の総実害が単調に減るとは限らない。3→3の重複更新と、解除/毒交換後の新規付与を分ける。

ヤヌスの清めは、毒がない入力時には予約できず予防ではない。速度57の清めの後に速度39のナーガが毒を付け直す場合もある。4種類を必要とするヤヌスと、3体条件の不死/粘体/悪魔中核は、同時に条件を満たして5枠へ入れられない。ヤヌスとドラウグルを並べる場合は基礎14の交換であり、不死3体の22とは分けて記録する。粘体補給はヤヌス/ドラウグル本人へ届かない。

毒の経過ダメージが少ないだけで無用と判定しない。実際に行われた解除の手番・MP・回復量・ヤヌスの一回分消費も示す。ただし元から必要だった回復付き清めを、全て無駄な手番を強制したと扱わない。毒交換の追加基礎や捨てた残り回数は潜在量であり、同じ命中の乱数・保護・端数・残HPによる追加実ダメージと区別する。守護の防いだ量も実害の倍算ではなく、同じ命中で守りだけを除いた状態との差を再構成する。既存の付与回数/守護回数をそのまま実効量と言い換えない。
