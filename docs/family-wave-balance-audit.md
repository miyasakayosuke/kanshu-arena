# 系統追加のバランス検証記録

## この記録で分かること

追加した個体・系統支援の固定条件における挙動を測った開発用の記録です。勝率50%への自動調整、プレイヤーの楽しさ、公平感、人間の最善手の証明ではありません。フェンリルや既存個体の能力値を一律に弱める実験は行っていません。

両軍の指示は本番 `autoOrders`、解決は本番 `advanceWithEvents`。例外の手動初手診断は別項目に分離しました。詳細な実行・指標・再生方法は [Balance Lab](./balance-lab.md) を参照してください。

### 最初の固定検証群と飽和

32の固定シード、各シードで両方の物理サイド、同じ方策。10編成・25対面・10ミラー・2候補版で4,480試合／設定。対面ごとに64試合／候補版ですが、同じシードの2方向を独立した64シードとは扱いません。

- 全獣 `[12,0,2,11,13]` はCOST17。
- 全自然 `[14,3,6,9,10]` はCOST15。
- 混成獣 `[12,0,2,6,10]` はCOST15。
- 解除技所有編成 `[8,11,2,6,10]` はCOST14。所有していても自動方策が必ず解除技を選ぶわけではありません。

全自然は最初の非玄武対面8種類ですべて64勝0敗でした。障壁だけを20→15%または無効にしても、その勝敗は変わりませんでした。しかし、障壁が無意味という解釈もできません。例えば先制編成相手の残HP割合は32.5%から障壁なしで16.3%へ下がり、平均ターンは2.91→3.44でした。

| 初期全獣の相手 | 全獣スコア |
| --- | ---: |
| 混成獣 | 7.8% |
| 先制 | 28.1% |
| 毒＋浄化 | 87.5% |
| 解除技所有 | 43.8% |
| 同コストの核なし全獣 | 71.9% |

同コストでない対面を含みます。全獣であることだけで強さを保証せず、回復・毒・範囲攻撃・速度の構成差を残して読みます。

### 単独の数値・役割変更では説明できなかった

次をそれぞれ単独に比較しました：玄武の攻撃45→30、全体威力46→32、回復70→55、守護技を除去、障壁20→15%／無効。いずれも最初の全自然の非玄武対面の勝敗は飽和したままでした。

攻撃30＋全体威力32の明示的な複合候補は、先制相手の玄武の直接ダメージを155.3→106.0、チーム残HP割合を32.5→25.4%へ下げましたが、同対面は64勝0敗のままでした。回復55は固定25対面で勝敗を一つも変えず、守護を除くと代わりに回復を選ぶ局面が増えました。

全体技だけを除いても、全自然は混成獣に96.9%、当初の核なし自然対照に93.8%。一方、**全体技と障壁を同時に除く**と、その核なし対照へのスコアは3.1%まで下がりました。単独除去で勝率が変わらないことは、効果の不足ではなく代替性・相互作用を隠していました。

### 正確な1枠置換と既存の毒4枠

当初の「核なし自然」は2枠変更を含み、玄武の増分を直接示すには不十分でした。追加で他4体 `[3,6,9,10]` を固定し、玄武だけをトロルまたはセルキーへ置換しました。さらにドリュアスを先頭に固定した `[3,14,6,9,10]` と `[3,1,6,9,10]` / `[3,7,6,9,10]` も比較しました。

コストは玄武版15、トロル版13、セルキー版14。1枠の変更でも本体能力・技・支援がまとめて変わり、コストは揃いません。先頭も変わる対照と、先頭を固定する対照を区別します。

| 初期案の編成 | 先制相手 | 既存の毒4枠・妖狐先頭 | 既存の毒4枠・ガルーダ先頭 |
| --- | ---: | ---: | ---: |
| 玄武先頭 `[14,3,6,9,10]` | 100% | 100% | 100% |
| トロル先頭 `[1,3,6,9,10]` | 62.5% | 0% | 0% |
| セルキー先頭 `[7,3,6,9,10]` | 3.1% | 3.1% | 3.1% |
| 玄武先頭・全体技と障壁を除去 | 100% | 7.8% | 3.1% |

毒4枠は `[0,3,4,9,10]`（COST15）と `[6,3,4,9,10]`（COST13）。先頭をドリュアスに固定しても、玄武ありと置換の間で同じ方向の大きな差がありました。初期玄武の追加効果を「既存の毒だけ」と片付けることはできません。

### 広い合法対戦群と手動初手の限定診断

16固定シード・両サイドで、明示的に保存した合法生成30編成と対策7編成へ全自然を当てました。生成チームのうち6つは玄武を含むため分けて集計しました。非玄武の31対面では969勝23敗／992試合（97.7%）でした。

全勝を崩す非玄武の対面は存在し、`[8,12,2,9,5]` と `[8,6,3,12,11]` への全自然スコアは16シード検証で各75%。同じ2対面を32シードへ増やすと75.8%・71.9%でした。対面選択・試行数に依存する数値で、全編成の勝率ではありません。

烏天狗をトロルに替えた4自然・毒2枠の案は、同じ非玄武対戦群で862勝124敗6分（87.2%スコア）となりました。ただし毒の人数だけでなく技・速度・耐久・対象系統も変わるため、これを家系の公平性や核の弱体化の根拠にはしません。元の合法な毒3枠編成は消えていません。

別の手動初手診断では、全獣の妖狐・アヌビス・ラタトスクの先制技とフェンリルの単体技を烏天狗に集中し、バステトはドリュアスを攻撃。その後は両軍の自動方策へ戻しました。32シード・両向きで烏天狗を1ターン目に倒したのは60/64試合ですが、全獣は0/64勝でした。これは指定した一つの対処だけの結果で、人間の対策全般を否定しません。本番AIは変更していません。

ラタトスクの連撃を威力0→5とする単独候補は小さい変化でした。威力0→10は、3/4発の条件・MP10・能力・フェンリルを維持したまま次の結果でした。

### 広い確認と支援の残る価値

最終ソース上の16シード・生成30＋対策7編成の確認では、元の毒3枠を含む全自然は非玄武31対面で844勝138敗10分／992試合、**85.6%スコア**でした。初期探索時の97.7%より下がっていますが、依然としてこの固定方策・対戦群では高い集計です。低い個別対面は20.3%・25.0%・31.3%・43.8%・34.4%など。追加の三重以上の全体攻撃編成には79.7%でした。

烏天狗をトロルに替えた4自然編成は、同じ非玄武集合で558勝432敗2分、56.4%スコア。これは元の全自然を置き換えたり、弱い例だけを「自然系の結果」として示したりするものではありません。

最終10%障壁を単独で外すと、全自然の先制相手スコアは100→43.8%、混成獣には92.2→84.4%。10%でも生存支援としての実効性があります。核が双方にいる対面では両方の障壁が変わるため、候補差が一方向に動くとは限りません。

物理allies側のミラースコアは、最終値の固定10編成で47.5%、広い39編成で51.5%、最終版対初期案の18編成で49.1%。近い値であることを公平性の証明に使いません。team Aに正規化した両向きミラーの50%は構造上の値です。

### 不確実性と次の判断

- 候補の探索と最終比較に同じシード・対面を再利用しました。独立の確認用シード、多重比較の補正、プレイヤー利用率の重み付けはありません。
- 記録した95%区間はシードごとの対応差に対する正規近似。固定対戦群内の参考値であり、0〜0の区間が出ても真の勝率や差を確定しません。
- 純粋な強さ、先手、家系ボーナス一つの因果効果とは区別します。対象選択・支援・乱数消費は候補で変わります。
- COST差・先頭・枠順・技の所有と実際の選択を確認します。解除技を持つだけの相手を、人間の最適な解除戦術とは呼びません。
- Lab関連148テストとTypeScriptを最終値で通過。最終リリースの全体テスト・ビルドは別の集約確認として行います。

この記録が支持するのは「新しい2系統の役割が作動し、元の全自然の支配的な初期案を弱め、具体的な対策が観測できるところまで確認した」ことです。楽しさや最終的な対人バランスの採用判断には、プレイテストが必要です。
