# Awakening detail preview candidate

Date: 2026-10-14. Base: accepted v0.20.32 tree 0b68d439d1d4eb794df3550a094d7219c8e32b37 plus existing isolated domain/storage candidate.

Open a monster profile, select 能力, then open 覚醒の能力を試算する. The disclosure begins collapsed and at zero. Native range input and stage 0 / 4 / 99 shortcuts plus single-stage buttons operate a local React state only. Current base values and hypothetical values are side by side, before leader effects. Browsing to another monster or closing and reopening resets the calculator. Enemy battle inspection excludes it.

HP and ATK derive from the original roster through the reviewed domain function. Approved ratios are 95 / 98 / 100 at stages 0 / 4 / 99, linear interpolation and nearest half-up integer rounding. Stage zero preserves current stats. MP and speed remain unchanged. Defense is not introduced. Next actual integer changes are shown separately for HP and ATK; a level does not promise an increase.

No save reads/writes, fake balances, rewards, inventory consumption, progression commits, battle integration, new backend, paid acquisition, or publication. The existing storage candidate remains isolated and unimported by production. This is a calculator UI, not a playable acquisition/progression loop. Actual progression requires approved economy/acquisition decisions and a browser transaction driver with integration/recovery tests.

New UI text, React/CSS, and tests were authored for this project with AI assistance. No third-party game text, artwork, audio, fonts, packages, or excerpts were added. Existing v0.20.32 artwork and third-party notices remain unchanged. Provenance review is not legal clearance.
