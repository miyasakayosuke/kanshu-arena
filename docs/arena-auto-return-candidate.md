# 対戦終了後は闘技場へ戻る

ユーザー指示（2026-10-13 JST）に合わせ、試合が終わると闘技場の受付へ自動で戻る。終了画面の再戦・編成変更の選択は廃止する。

- 通常再生では最後の攻撃・着弾・回復まで既存のタイムラインを完了してから戻る。明示的な「演出をスキップ」だけは既存どおり即時に確定状態へ進む。
- 勝利・敗北・引分の確定結果を同じ経路で処理する。受付には前の対戦の結果と数値だけを小さく表示し、必要なら「対戦の記録」を開いて既存の事実・根拠・全ターンのログを読める。次の対戦を始めると前の記録を閉じる。保存形式は追加しない。
- 自動で次の対戦は始めない。次の対戦は受付の出場ボタンで明示的に開始し、従来の通常対戦と同じ抽選を行う。
- 完了した戦闘の履歴項目は受付に置き換え、戻る・進むで終了画面に取り残さない。履歴復元が進行中なら完了を待ち、古い再生IDによる復帰は無効にする。
- 受付見出しへフォーカスを戻す。次の対戦ボタンへ勝手にフォーカスせず、押し続けたキーで対戦を開始しない。
- 中断確認は従来どおり。未完の対戦に架空の敗北・確定結果を付けない。中断して受付へ移動すると再生・入力タイマーを解除する。
- 選択したパーティ、3つの保存チーム、一時編成、図鑑の検索・絞込みは保持する。
