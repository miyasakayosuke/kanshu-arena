# 系統追加 第2波：ラタトスクと玄武

調査日：2026-10-09。今回のDQMSL参照は **新生ダーティラビッツ（2022-03-07）と新生ポセイドン（2020-09-15）の2体** に限定する。既存のフェンリルは引き続き2019年版新生ヘルゴラゴを参照する。異なる時期の参照を本作の同一ルールに合わせて設計するもので、DQMSLの特定時期の環境を再現するものではない。

名称・画・演出・能力値・COST・攻撃倍率は本作独自。実在の神話・伝承を名前と造形の着想に用いるが、DQMSLのキャラクター画像や文章を素材として移植しない。

## 選定理由と合法編成

- ラタトスク：低COSTの高速攻撃役。魔獣5体で増える追撃を持ち、全魔獣編成を選ぶ実益を作る。
- 玄武：鈍足・高HP/MPの自然系コア。開幕の軽減と回復で初手の速攻を耐え、残った敵へ反撃する。フェンリルと同じ速度競争だけを増やさない。
- 魔獣の例：フェンリル4、ラタトスク2、バステト3、妖狐4、アヌビス4でCOST17。妖狐かアヌビスをセルキー4へ替えられる。既存5体だけのCOST19という制約を、旧COST変更ではなく新しい選択肢で解消する。
- 自然の例：玄武5、ドリュアス3、ガルーダ2、ナーガ2、烏天狗3でCOST15。標準17と軽量15の両方に収まる。
- 新しく自然タグを設定する旧キャラは上記4体だけ。樹木、鳥、水辺の蛇、山の鳥という既存モチーフを使う。元の魔獣所属は維持し、全員を無理に分類し直さない。

「魔獣」「自然」は本作の編成用タグであり、神話の系譜、宗教上の分類、文化圏の分類を意味しない。既存メンバー4体を新たなDQMSLキャラへ一対一対応させたという意味でもない。

## 参照1：新生ダーティラビッツ

### 確認できた原作の仕組み

[公式・2022-03-07の新生説明](https://cache.sqex-bridge.jp/jp/ja/guest/information/83201)で確認：Sランク、素早さ+50、AI2回行動、開幕のみかわし、魔獣の素早さ+15%というリーダー特性を持つ。魔獣5体以上の編成では、HPへダメージを与える体技の後にランダムな敵1体へ無料のドロップキックが発生する。回復、補助、MPだけへの攻撃では発動しない。

本来のドロップキックは単体・無属性の体技。回避不能で、通常攻撃/斬撃の反射状態へ3倍になる。原作の反射対策と本作の守り解除は別の機能である。

[黒豆ブログ・2022-03-08の解説](https://mamepan.net/entry/dirty-rabbits-sinsei)では、ドロップキックMP38、全体の息MP124。高速の先行処理役だが、相手の生存保証や体技反射で処理しきれないこと、特技の付け替えと速度調整に左右されることが説明されている。

### 本作への取り込みと省略

- 「低COSTの速い仲間」「魔獣5体で追撃」の2点を主に取り込む。
- 代表技はランダム3発。戦闘開始時の5体が全員魔獣なら4発になる。戦闘中の撃破で編成条件を変えず、追撃から再追撃は発生させない。
- 原作の「対象となる体技なら追撃」を、本作では代表技だけに限定する。体技/斬撃/息の分類があるようには表示しない。
- AI2回行動、開幕回避、反射への3倍、特技付け替えは未再現。もう一方の先制単体技は本作独自であり、原作ドロップキックが先制技だったとは説明しない。
- 種弾の攻撃は独自創作。ラタトスクが伝承で種弾を撃つという主張はしない。

## 参照2：新生ポセイドン

### 確認できた原作の仕組み

[公式・2020-09-15の新生説明](https://cache.sqex-bridge.jp/guest/information/69686)では、自然のHP+40%/防御+20%がリーダー特性。自然全体への開幕軽減は1ラウンド目10%、2ラウンド目20%で、通常の強化解除や上位解除でも消えない。全体攻撃は自分の防御力に依存し、命中後に状態変化を解除する。

原作は回復行動に伴う防御上昇、自然5体で4ラウンド目以降に出る自動攻撃も持つ。[2018年の初登場公式説明](https://cache.sqex-bridge.jp/guest/information/38828)にあるガイアシールドは、戦闘中1回、先制で自然全体を1ラウンド90%軽減する特技。開幕の10/20%軽減とは別物である。

[黒豆ブログ・2020-09-16](https://mamepan.net/entry/poseidon-sinsei)によれば全体攻撃はMP65。防御成長、回復、解除を同時に使い分ける点が特徴であり、単に高HPで攻撃するキャラクターではない。

### 本作への取り込みと省略

- 取り込むのは自然限定のHP支援、開幕軽減、鈍足、高めのHP/MPという編成上の役割。
- 本作の開幕10%・2ターンの「自然障壁」は**解除可能**。原作の解除不能な10%→20%とは異なる。防御/守護とは軽減を重ねず、毒は軽減しない。この差は意図的な対抗策である。
- 本作の全体攻撃、回復、守護の数値や効果は独自。原作の防御依存攻撃や全体上位解除を再現したとはしない。
- 防御力・賢さ、蘇生、回復による防御上昇、90%の一度きりのガイアシールド、4ラウンド目以降の自動攻撃、属性/状態異常耐性は未再現。
- 回復や守護を使うとその手番は攻められない。軽減解除、毒、MP圧迫、期限後の集中攻撃を、本作で実際に使える弱点として残す。

## 実戦ブログから分かったことと限界

### 魔獣の実績は、特殊ルールと他の中核の強さを含む

[黒豆ブログ・邪獣杯第2週、2022-03-07](https://mamepan.net/entry/jaju-hai-2)は、ウェイト120・SS2体制限で新生ダーティラビッツを採用し、初日にカイザー★3へ到達した実戦記録。ヘルゴラゴとキングレオを中心に、残りをS以下にできる利点が語られる。一方、著者自身が勝因を強力な中核2体にも帰しており、ダーティラビッツ単体の勝率証明ではない。短期決着、反射処理の難しさ、先制の状態異常への弱さが見える。全5体の画像・育成条件は今回完全には確認できていない。

### 自然の実績は、低速でも戦える役割分担の根拠

[じゅんのーと・2020-11-03](https://www.jun-note.com/entry/dqmsl-sizen-party)は、自然編成への変更後に勝率が上がったという本人の報告と、ポセイドン/アマカムシカ/バルケロス/エビルトレント/盾役の構成例を載せる。数値化された勝率、試合数、全育成条件はないため、統計的な強さとは扱わない。

[とりき・2021-04-29](https://atoritori.hatenablog.jp/entry/2021/04/29/165226)は、コア、火力、盾、回復、自由枠という役割分担を説明。速度競争への依存が小さいという設計上の対照に使う。

[海鳴り屋かん・2023-10-30寄稿](https://mamepan.net/entry/kan)は、後年の自然では初手の軽減だけでなく、解除から次手の制圧へつなぐ順序が重要だと示す。ただし新キャラと後年環境を含むので、2020年版の数値・勝率へ混ぜない。この制圧を担う行動不能技は本作にない。

これらは当時の育成、ルール、対面、使用率ボーナスを含む歴史的な個人記録。今回のCOST17/15での勝率を保証しない。「原作で強かったから本作でも適正」とはせず、同じAI・同じ試行条件で検証する。

## 神話・伝承と造形

- ラタトスク：『ギュルヴィたぶらかし』第16章に登場し、世界樹を上下して鷲と蛇の間に言葉を運ぶリス。[一次文献の英訳](https://sacred-texts.com/neu/pre/pre04.htm)。素早い小動物と伝令のモチーフを使う。味方思いの守護者や種弾使いという設定は本文からは確認できず、本作独自の脚色とする。
- 玄武：亀に蛇が絡む姿、北と冬の守護のモチーフ。[奈良文化財研究所・キトラ古墳の解説](https://www.nabunken.go.jp/shijin/about/kitora-atlas/mural/post.html)。甲羅だけの巨大亀にせず、蛇を見分けられる造形にする。自然系リーダーとしての回復・戦闘能力は本作のゲーム設計。

## 次の系統候補

今回は2体で止め、まず合法な全魔獣と全自然を遊べる状態で確かめる。

1. ドラゴン：次の候補。既存の竜モチーフを足場にできるが、魔獣と同じ高速物理だけにはしない。息/呪文など攻撃種別を実装するか、属性や行動順で別の意味を作れるかを先に決める。
2. 物質：後攻の反撃や守りを崩す編成として検討。自然と違う耐久の仕組み、重装/機械モチーフの新メンバーが必要。現時点で防御力や復活を前提にしない。
3. ゾンビ：蘇生や倒れた後の行動が系統の個性に関わるため後回し。現状の毒だけで原作のゾンビ系統を再現したとはしない。

## 最低限の検証項目

- 開始時の全魔獣と魔獣4体で連射数が異なる。撃破後も開始編成条件が保たれ、追撃が再帰しない。
- 自然のHP支援と護りが非自然へ漏れず、敵味方で同じ処理になる。回復上限はリーダー補正後の最大HP。
- 護りの期限、解除、防御/守護との非重複、毒の軽減対象外を確認する。
- 先に解除する技と、フェンリルの命中後解除で初撃ダメージが正しく異なる。
- 全魔獣COST17、自然COST15、MP圧迫/毒/解除の混成で、同じAI・複数シードの試合を比較する。条件と試合数を明記し、単発の勝利から有利不利を断定しない。
- MP不足、行動前の撃破、対象の途中撃破、再戦、通常再生/倍速/スキップでも同じ結果になる。
