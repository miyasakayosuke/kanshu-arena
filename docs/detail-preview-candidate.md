# Detail reading creature preview implementation (v0.20.21)

Based on public v0.20.20 commit 117c988d0c6cd8c0488b365d7e2a4d37f17f24ed, exported staged tree d2f69d28a56e51276c00a5925526a8b67e8276e7.

The story, ability and skill tabs now retain one decorative original creature illustration beside the existing name. The illustration sits outside the reading scroll. Short/narrow viewports use a 32–44px thumbnail beside the name within the existing header structure. A wrapped name can increase header height. At viewport height >=700px and width >=381px it grows to 92×76px. At extreme widths <=300px, the title/preview and 44px navigation controls use two header rows to avoid overlap; the remaining reader scrolls locally. The large appearance artwork/content and optional movie entry remain unchanged; the extreme-width header reflow also applies to Appearance and standalone profiles.

Reuses HomeIdleArt and useHomeIdleVisibility without changes to their geometry, quiet idle tracks, native SVG lifecycle, static fallback, reduced-motion behavior or document/intersection pause. Returning to Appearance unmounts the one preview. Switching reading tabs retains the same SVG instance; browsing identities keys only the art instance. No JavaScript animation loop, game state, save, RNG, battle timing or media was added.

All 37 artwork/name identities are tested through catalog browsing. Existing page/skill reset, full text, keyboard ownership and movie regression tests remain applicable. Automated cascade and happy-dom tests do not prove rendered browser geometry. Native acceptance after exact deployment must check all 106 full effect/story readings and all 37 story tabs at both 360×533 and 400×606, narrower/short and tall layouts available through native window controls, enlarged browser zoom, long names with catalog navigation, Yoko/Fenrir silhouettes, background pause and nested movie focus. Record actual dimensions and unavailable device/reduced-motion tests. This implements only the general principle of keeping the selected creature visible while information changes.
