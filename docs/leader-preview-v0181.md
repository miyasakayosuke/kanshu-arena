# v0.18.1 リーダー比較の小さなUI修正

2026-10-10 UTC。別作業ツリーでのローカル候補。公開済みv0.13、凍結v0.18 tree `fd399cd61a4e068b4f675ea041f0b20494330748` はそのまま保存した。

## 目的と範囲

先頭の効果の説明だけでなく、現在のメンバーに実際に適用した場合の数値差を、確定前に読めるようにする。既存メンバーを先頭へ移す操作と、1枠目へ新候補を入れる操作を対象とする。追加/離脱した別の個体を、同一個体の強化として表示しない。

変更は編成画面の比較、独自の短い説明、検査だけ。戦闘エンジン、ロスター37体、HP/MP/攻撃/速度の基礎値、特技、系統、中核、AI、保存形式、アート、音、依存ライブラリは変更しない。型検査・全件テスト・権利表示・ビルド・smokeの結果は別途追記し、未実施を成功にしない。

## 背景

固定の失敗対面では、マモンからコボルトを先頭へ変えると悪魔3体だけのHP合計が54減る。一方、セルキー/バステトの速度61/57は変わらない。マモン自身は61→63でも、仲間の2手目を失う失敗があった。これを単に『素早さ+8%は強い』という見方へ単純化しない。

原作記事・コメントはこの問いを選ぶ着想であり、表示の数値は本作の実装から計算する。記事本文・画像・音・コードを取り込まない。新しい勝率試験や能力調整を行う修正ではない。過去の混成対策/先頭変更の不合格結果は書き換えない。

## 表示上の約束

- HP・MP・攻撃・素早さの実数を比較。対象/対象外と、効果を失うメンバーも明示する。
- 丸めを別実装せず、実戦開始時のリーダー適用と同じ値を使う。開幕の群気・障壁は別表示とし、この比較へ混ぜない。
- 行動は技の優先度が先、その後に素早さ。同じ優先度・素早さなら抽選。敵や指示を未選択の編成画面から、必ず先手になると約束しない。
- 比較だけでは編成/保存を変えない。既存の確定とキャンセル、フォーカス、再編集を保つ。
- 狭い幅でも情報を折り返し、詳細を開閉できる形にする。自動DOM検査を実ブラウザーの画面確認と呼ばない。
