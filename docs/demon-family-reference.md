# 悪魔系5体の参照資料と独自設計案

調査日: 2026-10-10 UTC。調査時の本作はID0〜28まで実装された粘体系作業版。**この文書は設計候補であり、採用値・実装済み仕様・バランス結果ではない。** `AGENTS.md` と `docs/rights/release-checklist.md` を確認した。調査担当は本ファイル以外を編集していない。

## 1. 推奨する最小案

- トロル（ID1、C3）とイフリート（ID8、C3）を、既存数値・技を変えずに本作の悪魔系へ所属させる。
- 新規は中核C5、速い解除役C2、単体攻撃と小さな清めを選ぶC4の3体。純5体は **3+3+5+2+4=17**。C15の純5体は成立しないことも明示する。
- 新機構は、**有料の単体攻撃に付随する小さな敵MP減少**を第一候補にする。自身へMPを戻さないので「吸収」とは表示しない。行動停止、呪文耐性、反射、蘇生、敵の強制身代わり、追加行動は入れない。
- 狙いは「速い解除役で守りを開け、相手の残MPを見て中核のMP削りかHP攻撃を選び、既存の遅い打撃へつなぐ」。全員による連撃、毒連打、HP回復ループは役割にしない。
- 歴史的参照は二つに分ける。タイタニス／フォロボシータからは**強化・解除と攻撃の順番、高い支出をいつ使うか**を学ぶ。敵MPへの圧力は、悪魔系ブギーの別の実例を参照する。**タイタニスがMPを奪う、あるいは原作の悪魔全体がMP削りを中核にしていたとは述べない。**

### B. 保留: 味方の解除に反応する一度のMP効果

2021タイタニスの「剥がすか残すか」という判断には近いが、誰への解除で発動するか、連撃途中で何回起きるか、死亡時・自身への解除・敵の解除分類・持続を追加する必要がある。本作では解除が既存中核への重要な対策なので、それを一方的に罰すると選択肢を減らす。今回の第一候補にはしない。後から採用するなら、無限反応、速度上昇、ダメージ50%強化を一括で持ち込まない。

## 7. MP削りを小さく、読めるものにする契約

以下は実装前に決めるべき仕様。A案の推奨値で記す。

1. HP攻撃を処理し、対象が生き残った場合だけMPを減らす。減少は `min(現在MP, floor(6または10 × directDamageScale))`。MP側には乱数・ATK倍率・連撃・全体化を使わない。MP0なら減少0であり、負値や自身の回復はない。
2. 無解除の爪に対する守りはHPとMPの両方を半減し、MP減少は3/5。自然障壁だけなら現行10%軽減で5/9。先にコボルトが守りを外すこと、守護の対象を読むこと、次ターンに守りを張り直すことに意味がある。既存の守護・防御は通常技より先に動くので、同じターンの通常順解除の後から張り直せるとは説明しない。
3. 自身のMP64から16を払うので、現行仕様では最多4回。粘体系補給の対象は生存している味方の粘体系だけであり、悪魔系のマモン本人は補給を受けない。合計減少は未軽減・全対象生存でも24/40で、使い手もMP64と4手を支払う。悪魔3体と粘体系補給3体は5枠で同時成立しない。マモンを含む悪魔2体と粘体3体なら補給条件は成立するが、受け取るのは粘体だけで、マモンのMP削りは基礎6のみとなる。特殊な資源回復を後日加える時はこの上限を再確認する。
4. HP基礎は63.3で、もう一つの攻撃は85.3。相手MP0・無料攻撃主体・即座の撃破が欲しい局面では後者が有力。MP削りが追加HP火力まで常に優れる設計にしない。
5. 相手の注文内容を見てMP削り量を変えない。公開された残MPと既知の技価格だけを読ませる。受けた側にも「MP−実減少量」と残MPを示し、HPダメージと別の色・別の数値にする。
6. 開戦条件、軽減後の量、命中前解除との関係はプロフィール、選択画面、戦闘ログ、巻き戻さない再生イベントで一致させる。

### 行動直前のMP不足: A案で採用する暫定契約

指示時の資金チェックは変えない。**もともと払えない技を選んで後の供給を待つことはできない。** 適法に指示した有料技が、今回導入する敵MP削りによって行動直前に払えなくなった場合は、次の契約を第一候補として確定する。これは本作の独自設計であり、原作の処理を再現したという意味ではない。

- 元のキュー位置で一度だけ無料の通常攻撃へ切り替える。MPは消費せず、「敵のMP削りでMP不足、通常攻撃へ変更」とイベント・ログで明示する。行動順の再抽選、速度上昇、追加行動はない。アンカー指示だった場合もその遅い位置のまま。
- 元の有料技のMP削り、解除、連撃、回復等は引き継がない。通常攻撃だけを処理し、有料の竜攻撃として竜気を増やさない。倒された者は攻撃しない。指定した敵が倒れた場合は既存の通常攻撃の対象選択規則へそろえる。元が回復・守護等の味方対象指示なら、その味方を攻撃せず、生存する敵へ通常攻撃の対象を選び直す。
- 注文履歴には選んだ技、実行イベントには変更後の通常攻撃と変更理由を残す。不正注文、初めからMP不足の注文、戦闘不能はこの救済の対象ではない。敵MP削りとの因果を区別し、将来の別の消費や不正状態へ無条件に広げない。
- 有効な指示の後でMPを削られても、行動前に適法な補給を受けて支払えるなら元の技を使う。一方、指示時に却下された技はその後の補給でも復活しない。 これは補給対象である粘体系の指示についての規則であり、マモンが補給を受け取れることを意味しない。

**無言の毎ターン行動消去は受入不可。** 不発と通常攻撃化は強さが違うので、比較の途中でこっそり変えない。初回案はMP64と消費16による最多4回を使い、追加の使用回数カウンターを設けない。Labで問題が見つかれば、量・速度・HP打点から調整する。

## 8. 有利にしたい状況、苦手、検証

これは本作の仮説であり、原作の評価を本作の勝率へ移したものではない。

- 得意にしたい: 強い有料技の次回使用が残MPぎりぎりの相手、守護を外せば後続が届く相手、HP攻撃と資源攻撃の優先度が変わる長めの対面。
- 苦手を残す: 先制や高SPDで中核を倒す編成、強い無料通常攻撃、複数の攻撃役への分散、温存した一度の粘体補給、守護での半減、MP削りを無駄にさせる低MP相手への対象変更。毒で清めを強制されることも手番の負担になる。
- 純悪魔には専任の大回復役を置かない。HP30の清めでは持久力が足りない可能性があり、長期戦は双方のMP不足だけでなく、悪魔側のHP不足でも負けられるようにする。
- C2高速解除の価値が高すぎると全ての混成で必須になる。低ATK・小HP、技のMP12、群気を外せない範囲を維持し、汎用優位を測る。
- 「相手から嫌われそう」と推測する要素は、指示後の不発、少額MPを連続で削られる停滞、解除をしても損をする反応特性。これは本案のUXリスクであり、取得コメントの多数派意見とは称さない。

最低限のLab・テスト:

1. 純5体C17、中核非先頭、3体、2体、単独、中核置換を同じAI・シード・左右交換で比較。中核リーダーと既存トロルリーダーを両方使う。
2. MP削り無効、6固定、10条件付き、12等の探索値を同じHP威力のまま比較。家族条件と単なるC5高数値を分離する。回数制限を採用するなら制限なしと別の記録にする。
3. 獣速攻、自然C15、竜・物質・粘体C17、無料攻撃主体、毒/清め混成、強い合法のC15/16/17混成を含める。相性の悪い既存編成を除外しない。
4. 勝率・ターン・引分に加え、実MP減少総量、減少0、守りで防いだ量、残MP不足による不発/通常攻撃化、通常攻撃回数、MP技とHP技の使い分けを記録する。AIはMP0相手へ無意味な削り技を連打しないが、敵の非公開注文は参照しない。
5. ターゲットが先に倒れた場合、爪で倒した場合、MP1/5/6/9/10/16境界、守護・障壁・解除の順番、先制行動後、後攻注文前、3体条件を満たした味方の死亡、供給前後、同時全滅と再戦を検証。
6. 倍速・スキップ・通常再生でHP/MP・ログ・最終状態が一致し、敵だけのフィールドと静止味方アイコン、旧保存、最大4特技、30秒入力を維持する。
