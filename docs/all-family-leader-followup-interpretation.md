# Interpreting the frozen leader and Janus follow-up

## The leader hypothesis fails the required robustness screen

All 71,040 scheduled executions completed and every row passed exact source/config/schedule/result binding. The 120 fixed replay samples, 5,920 stock-identity comparisons and 30,800 repeated-baseline comparisons passed. No additional seed, leader or roster was substituted.

The new Kobold-led demon lineup and the original material counter both pass the two-shell conditions at zero under independent AUTO. They fail under reservation, so the predeclared both-policy leader screen has no selected scale. The original systemic mixed-counter protocol also remains failed.

At zero/reservation, the new demon leader scores only 17.97% versus Dryas and 20.31% versus Tengu. Its paired score changes relative to original Mammon leadership are −42.77 points (approximate seed-clustered 95% interval −52.02 to −33.53) and −42.58 points (−51.35 to −33.81). The original material counter also fails at 40.63% and 43.36%. These adverse results remain in the full tables.

The independent-arm improvement does not make the leader swap a general counter. The swap changes speed, starting HP, slots and random/planning allocation together; this study cannot attribute the reversal solely to the 54-HP loss or solely to initiative. No further leader search is authorized by these results.

## The separate Janus recommendation comparison is favorable

At zero/reservation, using the same common 23 opponents for both targets:

| Target | Common 23 score | Strict C17 score | Common mean turns |
| --- | ---: | ---: | ---: |
| Original four-tag Janus | 25.14% | 18.75% | 7.47 |
| Pre-existing five-tag Janus | 58.29% | 51.97% | 6.48 |

The paired improvements are +33.15 points for common 23 (approximate seed-clustered 95% interval +27.74 to +38.56) and +33.22 points for the common 19 C17 opponents (+27.74 to +38.71). Each comparison uses 16 fresh seed clusters and both orientations. Both target comparisons exclude the original Janus identity; raw 24-cell tables and the self mirror are retained separately.

The five-tag absolute strict-C17 interval is 48.69–55.25%. This is not proof of an above-50% population win rate, and 50% was not a tuning target. The recommendation was chosen adaptively from an earlier pre-frozen alternative, not blindly. Its improvement does not replace an original fixed counter or pass the failed leader protocol.

## Equal response allowance, different composition

Four and five tags both qualify for exactly one equal-strength response allowance. Per common-opponent game at zero/reservation:

| Actual metric | Original four-tag | Five-tag |
| --- | ---: | ---: |
| Eligible allowance | 1.00 | 1.00 |
| Executed response casts | 0.583 | 0.569 |
| Cleanse / guard responses | 0.466 / 0.117 | 0.480 / 0.090 |
| Response MP spent | 13.99 | 13.66 |
| Cleared poison ticks | 3.45 | 3.63 |
| Response guard HP prevented | 13.32 | 10.59 |
| Unused allowance | 0.417 | 0.431 |
| Died with unused allowance | 0.370 | 0.321 |
| Cancelled response selections | 0.087 | 0.106 |
| Direct HP damage | 868.39 | 882.45 |
| Tick HP inflicted | 0.00 | 108.39 |
| Effective HP healing | 92.89 | 0.00 |
| Total MP spent | 173.10 | 167.21 |
| Deaths before a queued action | 1.59 | 0.76 |

Rejected, no-effect and fallback response casts are zero in both of these aggregate panels. The response is withheld for about 2.19 and 2.15 turns per game respectively. A response uses an action and MP; cleared-tick nominal future damage is not guaranteed actual HP prevention. The improvement is not evidence of a stronger five-tag response: it occurs with slightly fewer response casts, less response guard prevention, a new poison contribution and different survival/action patterns. These correlated observations do not isolate one causal component of the composition change.

## What remains for the parent

The fresh pure-family confirmation supports zero under both policies, while the full original distribution argues against zero with old independent AUTO. Reservation still has the first-selected-caster death risk, pure nature is C15 and has severe C17 matchup polarity, and strong pure demon has its own losing cells. The parent must assess those limits, player-visible explanations and manual counterplay before any bounded playtest adoption.

No engine, family, core, CLI, production default, cost, skill, stat or original CPU roster changed in this study worktree. All original failed probes, the failed leader follow-up, all scales and both policies remain preserved. Publication is a separate blocked operation, not authorized by these findings.
